Install an app from this PC

Choose an IPA. AltKeeper signs it with the configured Apple ID and installs it over Wi-Fi. The Apple ID password must be saved on the server.

These settings are for new installations only. Existing apps and automatic renewal are never modified. A new Bundle ID allows a separate copy; the Apple team suffix is added automatically.

Confirm new installation

Unchecked extensions are removed before signing. Some apps require extensions to function. All are selected by default.

App ID count is an upper bound; already-registered IDs may be reused. Live Apple quota is not checked here.

Automatic renewal

Runs once daily while this server is online. Renews expiring installed apps. If installed-app lookup fails, it falls back to all saved-team profiles. Default is OFF.

OFF Automatic renewal disabled

If a scheduled renewal fails: retry after 30 minutes, up to twice more. Send Discord notification only after the final failure (or an unretryable authentication error).

Not configured Only sent when automatic renewal fails after retries.
