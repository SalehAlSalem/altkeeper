How to connect Discord notifications?

Get alerted on Discord only if automatic renewal completely fails.

1 Open Channel Settings

In Discord, right-click the text channel where you want notifications (e.g. #alerts) and click Edit Channel.

2 Create a Webhook

Go to the Integrations tab, click Webhooks, then click New Webhook.

3 Copy Webhook URL

Click Copy Webhook URL. The URL looks like this:

https://discord.com/api/webhooks/... (click to copy prefix)

Paste it into the Discord failure notifications field below and click Save webhook.

How to connect Telegram Bot?

Follow these 3 simple steps to receive renewal failure alerts on Telegram.

1 Create your bot with BotFather

Open Telegram and search for @BotFather.

Send /newbot, choose a name and username. BotFather will reply with your API Token:

Token format: 123456789:ABC...
2 Start your bot

Search for your new bot's username on Telegram and click Start so it has permission to message you.

3 Get your Chat ID

Search for @userinfobot on Telegram and send any message.

It will reply with your numerical Id (e.g. 987654321). Paste both the Token and Chat ID below and click Save bot.
